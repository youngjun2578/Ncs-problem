진단하는 4개 영역

  1. 기초연산

    업무 상황을 식으로 옮기고 사칙연산·비율 계산을 정확하게 하는지 봅니다.

    거리·속력·시간, 농도, 일의 양, 할인·이익, 나이·연령, 증가율·비율, 단위 환산, 방정식 응용

  2. 기초통계

    대푯값과 경우의 수·확률로 자료를 요약하고 가능성을 계산하는지 봅니다.

    평균, 중앙값, 경우의 수, 확률, 순열·조합

  3. 도표분석

    표와 그래프에서 필요한 수치를 찾아 증감률·비중·배수를 계산하는지 봅니다.

    증감률, 비중, 배수·차이 비교, 증가율 최대 시점, 1인당 수치, %p와 % 구분

  4. 도표작성

    자료를 목적에 맞는 그래프로 옮기고 눈금과 항목을 정확히 대응시키는지 봅니다.

    그래프 종류 선택, 막대·꺾은선·원그래프 작성, 증가율 그래프 작성

영역 구분은 수리능력의 하위 능력을 학습 목적에 맞게 정리한 것으로, 기관마다 실제 출제 구성은 다를 수 있습니다.

진행 방식

  1. 문항마다 보기를 고르면 바로 다음 문항으로 넘어갑니다. 정답은 마지막에 한꺼번에 공개합니다.
  2. 화면 위쪽 진행 바에서 남은 문항과 경과 시간을 확인할 수 있습니다.
  3. 문제는 풀 때마다 숫자와 문장이 새로 만들어지므로 여러 번 다시 풀어도 됩니다.

예시 문항

배송 차량 한 대가 물류센터에서 거래처까지 시속 40km로 갔다가 같은 경로를 시속 60km로 되돌아왔다. 왕복 전체의 평균 속력은 시속 몇 km인가?

  1. ①시속 24km
  2. ②시속 40km
  3. ③시속 48km
  4. ④시속 50km
  5. ⑤시속 60km

정답은 ③ 48km입니다. ④ 50km는 두 속력을 단순 평균했을 때 나오는 값으로, 이런 보기를 고르면 리포트에 "산술평균 착각" 패턴으로 표시됩니다.

연습용 진단입니다. 모든 문제는 직접 만든 템플릿에서 생성되며, 특정 기관의 실제 시험 문제나 출제 경향과 같다고 보장하지 않습니다. 영역당 문항 수가 적어 결과는 참고용입니다.
