문제 생성·검증 방식

이 진단의 문제는 어디서 가져온 것이 아니라 직접 만든 생성 규칙(템플릿)으로 매번 새로 만들어집니다. 만드는 방법과 검증하는 방법, 결과를 판정하는 기준을 모두 공개합니다.

1. 문제를 만드는 방법

  • 직접 제작한 템플릿. 유형마다 문제의 구조와 문장 틀을 직접 작성했습니다. 외부 기출문제나 문제집의 문장을 옮겨 오지 않았습니다.
  • 정답을 먼저 정하고 숫자를 역산. 예를 들어 농도 문제는 깔끔한 답이 나오는 조합을 먼저 고른 뒤 그에 맞는 소금물의 양과 농도를 정합니다. 그래서 답이 복잡한 소수로 끝나지 않습니다.
  • 오답은 흔한 실수에서. 오답 보기는 임의의 숫자가 아니라 "두 속력을 단순 평균", "기준량을 올해로 잡음"처럼 실제로 자주 하는 실수를 계산식으로 재현해 만듭니다. 각 오답에는 어떤 실수에서 나온 값인지 표시(실수 유형)가 붙어 있고, 결과 리포트의 "틀린 패턴"은 이 표시를 근거로 합니다. 실수로 만들 수 있는 오답이 부족할 때만 정답 근처의 값을 "계산 실수" 보기로 채웁니다.
  • 풀 때마다 다른 문제. 숫자, 등장 대상, 문장 틀이 매번 달라집니다. 같은 유형도 문장 틀을 3가지 이상 두어 같은 문장이 반복되지 않게 했습니다.
  • 도표는 가상 자료. 표와 그래프의 수치는 문제를 위해 만든 가상의 값이며, 실제 기관·기업의 통계가 아닙니다.

2. 정답을 검증하는 방법

정답은 사람이 입력하지 않고 문제를 만들 때 계산식으로 함께 계산됩니다. 여기에 더해, 사이트를 배포하기 전에 자동 검사(npm run validate)를 실행하며 하나라도 실패하면 배포 파일이 만들어지지 않습니다.

  • 유형마다 문제를 3,000번씩 생성해, 정답 보기가 정확히 하나 있는지 확인
  • 보기 5개가 화면에 보이는 형태로 서로 겹치지 않는지 확인
  • 문장·보기·해설·도표에 NaN, 음수, 정의되지 않은 값 같은 비정상 값이 없는지 확인
  • 정답이 소수 첫째 자리 이내의 깔끔한 값인지, 확률은 0보다 크고 1 이하인 기약분수인지 확인
  • 모든 오답에 실수 유형이 붙어 있는지, 근접값으로 채운 오답이 지나치게 많지 않은지 확인
  • 12문항 세트를 3,000개 만들어 영역별 3문항씩 서로 다른 유형으로 구성되는지, 같은 세트 안에서 문장이 겹치지 않는지 확인
  • 그래프를 고르는 문제는 보기 그래프 5개가 서로 다르게 그려지는지 확인

자동 검사는 계산과 형식의 오류를 막지만, 문장이 어색하거나 해설이 부족한 경우까지 모두 잡아내지는 못합니다. 이상한 문제를 발견하면 아래 문의처로 알려 주세요.

3. 결과를 판정하는 기준

영역마다 3문항으로 판정하므로 규칙을 단순하게 두었습니다.

  • 안정: 3문항 모두 정답. 단, 문항당 평균 시간이 권장 시간의 1.5배를 넘으면 보완 필요로 표시합니다.
  • 보완 필요: 정답률 60% 이상 (3문항 중 2문항)
  • 집중 필요: 그 미만

권장 시간은 기초연산·기초통계 문항당 75초, 도표분석·도표작성 문항당 90초로 잡은 연습용 기준입니다. 추천 학습 순서는 수준이 낮은 영역부터, 영역 안에서는 틀린 유형 → 이번에 나오지 않은 유형 → 맞힌 유형 순으로 정리합니다. 전체 점수는 참고 정보로만 보여 줍니다.

4. 영역 구분에 대해

기초연산·기초통계·도표분석·도표작성의 4개 영역은 NCS 직업기초능력 가운데 수리능력의 하위 능력을 학습하기 쉽게 정리한 것입니다. 실제 채용 시험은 기관마다 출제 구성과 난이도가 다르며, 이 진단은 특정 기관의 시험과 같다고 보장하지 않습니다.

5. 개인정보 안내

  • 회원가입, 로그인, 이름·연락처 입력이 없습니다.
  • 문제 생성과 채점은 모두 사용자의 브라우저 안에서 이루어지며, 풀이 기록과 결과를 서버로 보내지 않습니다. 이 사이트에는 답안을 받는 서버나 데이터베이스가 없습니다.
  • 쿠키, 방문 분석 도구, 브라우저 저장소(localStorage 등)를 사용하지 않습니다. 페이지를 닫으면 결과는 사라지므로 필요하면 결과 화면에서 인쇄하거나 PDF로 저장하세요.
  • 향후 광고를 게재하게 되면 광고 제공 사업자가 쿠키를 사용할 수 있으며, 그 경우 게재 전에 이 안내를 먼저 갱신합니다. 광고는 결과 화면 하단에만 두고 풀이 중에는 표시하지 않습니다.

6. 이용 시 유의사항

  • 연습용 진단이며, 결과는 합격 여부나 실제 시험 점수를 예측하지 않습니다.
  • 영역당 문항 수가 적어 같은 실력이라도 결과가 달라질 수 있습니다. 여러 번 풀어 경향을 보는 것을 권합니다.
